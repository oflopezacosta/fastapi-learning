\# FastAPI Learning Project



\## Description

A Python REST API developed with FastAPI as part of my AI engineering learning journey.



\## Technologies

\- Python

\- FastAPI

\- Uvicorn



\## Installation

```bash

python -m venv .venv

python -m pip install fastapi uvicorn

```



\## Run the application

```bash

python -m uvicorn main:app --reload

```



\## API Documentation

Once running, open http://127.0.0.1:8000
